# 🛡️ SentinelCI

A lightweight, custom Continuous Integration (CI) orchestration runner built entirely in Bash. 

## 🚀 Project Overview
SentinelCI automates the software build and testing lifecycle locally. It uses Git Hooks to detect code changes, compiles the target application, runs test suites, and provides real-time logging and notifications.

## 🛠️ Tech Stack
* **Core Automation:** Bash Shell Scripting
* **Trigger Mechanism:** Git Hooks (`post-commit`)
* **Target Application:** Java
